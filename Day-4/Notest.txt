HTML Elements : 
---------------
    ->Both opening tag and closing and content together is called as HTML Elements 
    ->Ex: 
        <h1>  HELLO   </h1>


    Types: 
        1. Block Level Elements 
            ->Any Elements which will consumes enter browser width 
            ->Ex: all Heading tags , sematic tags , p, div.. 

        2. Inline Level Elements
            ->Any Elements which will consumes only content width 
            ->Ex: span ,all formatting tags 



Tags In HTML: 
---------
    ->tags are the predefine words which are inclosed with both opening and closing angular brackets
    ->Ex: <h1>    </h1>

    Types: 
    -------
        1. paired tags 
            ->Any tags having both opening and closing tags 
            Ex: 
                i. formatting tags 
                    1. <b>  </b>
                    2. <strong> </strong>
                    3. <i> </i>
                    4. <em> </em>
                    5. <sub> </sub> 
                    6. <sup> </sup> 
                    7. <mark> </mark>
                    8. <marquee> </marquee>
                    9. <u>  </u>
                    10. <strike> </strike>

                ii . all heading tags 
                          <h1>heading tag-1</h1>
                          <h2>heading tag-2</h2>
                          <h3>heading tag-3</h3>
                          <h4>heading tag-4</h4>
                          <h5>heading tag-5</h5>
                          <h6>heading tag-6</h6>

                iii. others : 
                        Ex: <p> </p> , sematic tags ( <nav> </nav>, <footer> </footer> ..etc)

        2. unpaired tags / self closing tags 
            ->unpaired tags contains only opening 
            ->Ex: <br>  , <hr> , <input> , <col> ..etc

Attributes : 
------------
    ->Attributes are the additional information given to the tags 
    ->Attributes are always in opening tag 
    ->most of the Attributes are in key and pair 
    ->All  html Elements contains Attributes
    EX: 
        <h1 align="center">  Good Evening  </h1>




List In HTML : 
-------------
    ->List are used to display data in ordered or unordered way 

    Types: 
        1. Ordered List 
            ->when ever we want to display data in ordered format like numberings , alphabets .romanNo 
            -><ol> </ol> represent order list
            -><ol></ol> tags no. of list items (<li></li>)

            Order list Attributes: 
            ---------------------
                1. type : 1, a, A, i, I 
                2. start 
                3. reserved


        2. unOrdered List 
            ->when ever we want to display data in symbolic format like square , circle, disc  
            -><ul> </ul> represent unOrdered list
            -><ul></ul> tags no. of list items (<li></li>)
            unOrdered list Attributes: 
            ---------------------
                1. type : none , disc , circle , square 

        3. Description List /definition List 
            ->in html to represent Description list <dl></dl>
            -><dt></dt>  Description terms
            -><dd></dd>  Description data

       4 . Nested List
