Tokens: 
----------
    ->Tokens smallest  units in Javascript code 
    Types: 
        1. identifiers
            ->identifiers are names given to the code 
            Ex: variable names , class names , method/function names 
            ->in place of identifiers we can not use keywords


        2. keywords 
                ->keywords are the predefine reserved words 
                ->in Js total 66 keywords are there 

        3. literals
            ->literals are the values given to code 
            Types: 
                1. Numeric literals 
                2. String literals

        4. operators 
            ->operators are the symbols used to perform some operations on operands 
            ->Ex: 10 +20 

            Types : 
            --------
                1. Arithmetic operators  (+ ,- ,/ ,% ,** , *)
                2. Assignment operators (=, += ,-= , /= ,*=, %=)
                3. Relational operators (>,>= ,< ,<=)
                4. comparison operators (==, === , !=)
                5. logical operators (&& ,|| , !)
                6. bitwise operators (&, |, ^)
                7. shift operators (>>,<<)
                9. unary operators (++ ,--)
                10. ternary operators (condition ? statement1 : statement2)




        5. separators 
            ->separators are used to separate the give code 
                Ex: () ,{} ,[] ,<> , , , . , ; , : , "" ,'' , ``, 

        6. comments 
            ->comments are used to comment the given code 
            Types: 
               1. single line comments   // 
               2. Multi line comments   /* 
                                                */
